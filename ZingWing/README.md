# Zing Wing

Zing Wing is an Expo React Native productivity and self-improvement app for CSC457 Project 2. It turns real-life goals into missions, XP, ranks, routines, community posts, and leaderboard competition.

## Run

```bash
npm install
npm start
```

Then open the app with Expo Go, an emulator, or the web option from Expo.

## Main Features

- Stack, bottom tab, and drawer navigation with React Navigation.
- React Native Paper cards, buttons, text inputs, chips, switches, progress bars, avatars, and lists.
- Mission CRUD using local React state.
- XP, level, and rank system.
- Community progress posts with image picker.
- Country leaderboard with location permission demo.
- Dark and light mode saved with AsyncStorage.
- Local notification reminders for missions.
- Quote of the day from a public Web API.
- Mock JSON AI mission generator screen ready for Firebase Generative AI later.
